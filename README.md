# Sistema de Pedidos de Comida Local

Sistema web para gestionar pedidos de comida de una startup en Cusco.

## Objetivo

Organizar el código del proyecto desde el inicio utilizando control de versiones con Git.

## Herramientas

- Visual Studio Code
- Git
- GitHub

## Reflexión

**¿Por qué Git es crítico en proyectos colaborativos?**

Porque permite que varias personas trabajen sobre el mismo código al mismo tiempo sin sobrescribir el trabajo de las demás. Cada integrante puede desarrollar en su propia rama, y luego Git se encarga de combinar (merge) esos cambios de forma ordenada. Además, mantiene un historial completo de quién hizo qué cambio y cuándo, lo que facilita la coordinación del equipo y la revisión del progreso del proyecto.

**¿Qué problemas evita?**

- Pérdida de código por sobrescribir el trabajo de otro compañero al guardar cambios.
- Descoordinación al no saber qué versión del proyecto es la más reciente o cuál está en producción.
- Dificultad para volver a una versión anterior estable si algo se rompe.
- Falta de trazabilidad: sin Git es difícil saber quién introdujo un error y cuándo.
- Dependencia de copias manuales (carpetas tipo "proyecto_final_v2_definitivo") como forma de versionar.
